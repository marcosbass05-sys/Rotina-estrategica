# 🚀 Rotina Estratégica

Aplicação web para acompanhamento diário de rotina de **transformação pessoal e financeira**.

> Construir estabilidade financeira, disciplina mental, evolução intelectual e crescimento estratégico de forma consistente.

---

## ✨ Funcionalidades

| Aba | O que faz |
|---|---|
| **Hoje** | Anel de progresso, métricas do dia e linha do tempo com todos os blocos da rotina (05h40–23h10) |
| **Checklist** | 7 itens do checklist diário + análise de trabalho, entregas e mentalidade |
| **Financeiro** | Registro de bruto, combustível, KM e gastos → cálculo automático do lucro líquido e status da meta |
| **Planejamento** | 4 perguntas estratégicas para o dia seguinte + objetivos de 12 meses |
| **Semana** | Estrutura intelectual semanal + desempenho financeiro acumulado |

---

## 💾 Persistência de dados

Os dados são salvos automaticamente no **localStorage** do navegador.  
Os blocos do dia, checklist e campos financeiros são **resetados automaticamente a cada novo dia**.  
O histórico financeiro semanal é acumulado e mantido entre sessões.

---

## 🚀 Como usar

### Opção 1 — Abrir direto no navegador
Baixe o arquivo `index.html` e abra no navegador. Não precisa de servidor.

### Opção 2 — GitHub Pages (site online gratuito)

1. Crie um repositório no GitHub (ex: `rotina-estrategica`)
2. Faça upload do arquivo `index.html`
3. Vá em **Settings → Pages**
4. Em **Source**, selecione `main` e `/ (root)`
5. Clique em **Save**
6. Acesse em: `https://seu-usuario.github.io/rotina-estrategica`

## 📅 Estrutura da rotina

| Horário | Bloco |
|---|---|
| 05h40 | Despertar |
| 05h45–06h25 | Bloco mental (leitura · reflexão · planejamento) |
| 06h25–07h00 | Preparação |
| 07h00–08h00 | Trânsito estratégico |
| 08h00–18h00 | Trabalho gerencial |
| 18h00–18h40 | Trânsito retorno |
| 18h40–19h00 | Preparação entregas |
| 19h00–22h00 | Operação entregas |
| 22h15–22h40 | Fechamento do dia |
| 22h40–23h10 | Descompressão |
| 23h10 | Dormir |
